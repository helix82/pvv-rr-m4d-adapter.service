# pvv-rr-m4d-adapter Microservice

Микросервис для работы с API РР МЧД и ПВВ.

**Архитектура**

Микросервис построен на основе Spring Boot и работает по принципу REST API.

**Основные компоненты**

- Контроллеры: обеспечивают обработку входящих HTTP-запросов.
- Сервисы: реализуют бизнес-логику взаимодействия с API РР МЧД и ПВВ.
- Репозитории: взаимодействие с БД.
- Клиенты API: для отправки запросов в систему API РР МЧД.

**Основные возможности**

- Обращение к API РР МЧД.
- Обращение к API ПВВ.

# Продакшн-настройка pvv-rr-m4d-adapter

Для корректной работы микросервиса pvv-rr-m4d-adapter в продакшн-окружении требуется выполнить следующие шаги настройки.

1. **Подключение к системе ПВВ**

Для полноценного функционирования микросервиса необходимо обеспечить доступ к системе ПВВ.

Требования:

- Доступ к API системы ПВВ:

Убедитесь, что сеть микросервиса позволяет подключаться к API ПВВ. Если API защищено, убедитесь, что предоставлены необходимые данные для аутентификации (токены, ключи и т. д.).

- Настройка окружения:

Убедитесь, что в values хелмов указаны корректные данные


2. **Подключение к системе API РР МЧД**

Для полноценного функционирования микросервиса необходимо обеспечить доступ к системе API РР МЧД.

Требования:

- Доступ к API системы API РР МЧД:

Убедитесь, что сеть микросервиса позволяет подключаться к API API РР МЧД. Если API защищено, убедитесь, что предоставлены необходимые данные для аутентификации (токены, ключи и т. д.).

- Настройка окружения:

Убедитесь, что в values хелмов указаны корректные данные

3. **Настройка базы данных (PostgreSQL 14)**

Микросервис использует PostgreSQL для хранения данных.

Требования к базе данных:
- Версия: PostgreSQL 14.
- Создание базы данных:

Создайте базу данных для микросервиса с именем указанным в values хелмов, например pvv_rr_m4d_adapter_db.

**Предварительные требования**

- Java 11 Bellsoft Liberica Full
- Maven
- Postgres 14
- Доступ к системе ПВВ

P.S. Необходимо в values хелмов в значение tag добавить необходимый тэг образа.
